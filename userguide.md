
# Чат-приложение (Python + Sockets + Tkinter)

Простое клиент-серверное чат-приложение с графическим интерфейсом, поддержкой регистрации, общего и приватного чата, и сохранением истории сообщений.

---

## Состав проекта

| Файл         | Назначение                                   |
|--------------|----------------------------------------------|
| `server.py`  | Сервер: принимает соединения, обрабатывает сообщения |
| `client.py`  | Клиент с GUI (Tkinter), авторизация и чат    |
| `database.py`| SQLite база: хранение пользователей и сообщений |

---

## Использование клиента

1. Запустите клиент (`client.py`)
2. Введите никнейм и пароль
3. Нажмите "Зарегистрироваться" или "Войти"
4. Общайтесь в общем чате или откройте вкладку личного сообщения с другим пользователем

---

## Хранение данных

SQLite-файл `chat.db` создаётся автоматически и хранит:

- Пользователей (`users`)
- Общие сообщения (`messages`)
- Приватные сообщения (`private_messages`)

---

## Возможные проблемы и решения

| Проблема                            | Решение |
|-------------------------------------|---------|
| Клиент не подключается              | Проверьте IP сервера и открыт ли порт 5555 |
| Сервер не запускается               | Используйте `0.0.0.0` вместо локального IP |
| Ошибка "Никнейм уже занят"          | Зарегистрируйте другой ник |
| Сообщения не отправляются           | Убедитесь, что сервер работает и есть соединение |
