# Документация: Чат-приложение с использованием Socket Python

## 1. Краткое описание проекта
Это чат-приложение позволяет пользователям общаться в реальном времени через общий чат или личные сообщения. Приложение состоит из трех основных компонентов:
- **Сервер (server.py):** Обрабатывает подключения клиентов, маршрутизирует сообщения и взаимодействует с базой данных.
- **Клиент (client.py):** Предоставляет графический интерфейс для пользователей с использованием tkinter.
- **База данных (database.py):** Хранит учетные данные пользователей и историю сообщений.

### Основные возможности:
- Регистрация и аутентификация пользователей.
- Общий чат с историей сообщений.
- Личные сообщения между пользователями.
- Список онлайн-пользователей.
- Сохранение истории сообщений.

## 2. Файлы и их назначение

### client.py
Графический клиент чата, реализованный с использованием tkinter. Основные функции:
- Подключение к серверу.
- Авторизация или регистрация пользователей.
- Отправка и получение сообщений.
- Отображение списка онлайн-пользователей.
- Открытие приватных чатов с другими пользователями.

### database.py
Модуль для работы с SQLite базой данных. Содержит:
- Таблицу пользователей (никнейм и пароль).
- Таблицу сообщений общего чата.
- Таблицу личных сообщений.
- Методы для сохранения и извлечения данных из базы.

### server.py
Серверная часть приложения, отвечающая за:
- Прием новых подключений.
- Аутентификацию пользователей.
- Маршрутизацию сообщений между клиентами.
- Взаимодействие с базой данных.
- Поддержание списка онлайн-пользователей.

## 3. Основные функции файлов

### client.py
- **ChatClient** - основной класс клиента.
- **`__init__`** - инициализация интерфейса и подключение к серверу.
- **show_auth_screen** - отображение экрана авторизации/регистрации.
- **show_chat_screen** - отображение основного интерфейса чата.
- **send_message** - отправка сообщений (как в общий чат, так и приватных).
- **receive_messages** - поток получения сообщений от сервера.
- **open_private_chat_tab** - открытие вкладки приватного чата.
- **update_online_users** - обновление списка онлайн-пользователей.

### database.py
- **ChatDatabase** - класс для работы с базой данных.
- **_create_tables** - создание таблиц при инициализации базы данных.
- **save_message** - сохранение сообщения в общий чат.
- **save_private_message** - сохранение личного сообщения.
- **get_history** - получение истории сообщений общего чата.
- **get_private_history** - получение истории приватного чата.
- **register_user** - регистрация нового пользователя.
- **check_credentials** - проверка учетных данных пользователя.

### server.py
- **ChatServer** - основной класс сервера.
- **`__init__`** - инициализация сервера и базы данных.
- **_send_message / _receive_message** - методы для работы с сокетами.
- **broadcast** - рассылка сообщений всем подключенным клиентам.
- **handle_client** - обработчик подключения каждого клиента.
- **remove_client** - отключение клиента от сервера.
- **send_history** - отправка истории чата новому пользователю.
- **accept_connections** - основной цикл принятия подключений.

## 4. Как работает программа

### Запуск сервера:
1. Запускается файл **server.py**.
2. Сервер создает сокет и начинает прослушивать указанный порт.
3. Инициализируется база данных (создаются таблицы, если их еще нет).

### Запуск клиентов:
1. Пользователи запускают файл **client.py**.
2. Клиент пытается подключиться к серверу по указанному IP.
3. Отображается экран авторизации.

### Аутентификация:
- Пользователь может выбрать регистрацию или вход в систему.
- Сервер проверяет учетные данные в базе данных.
- После успешной аутентификации открывается основной интерфейс чата.

### Работа в чате:
- Сервер рассылает список онлайн-пользователей.
- Пользователи могут отправлять сообщения в общий чат или выбирать отдельных пользователей для приватного общения.
- Все сообщения сохраняются в базе данных.

### Завершение работы:
- При отключении клиента сервер получает уведомление о разрыве соединения.
- Сервер удаляет пользователя из списка онлайн и уведомляет остальных клиентов.
- Сервер продолжает работу, ожидая новых подключений.
